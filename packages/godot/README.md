# @aige/godot: Godot 4 C# export

AIGE authors games (scenes, procedural models, voices, cutscenes, story logic). **Godot 4 .NET runs them**: the realistic renderer (SDFGI, volumetric fog, SSAO/SSIL, glow), Jolt physics, and a native Windows build. Game code is **C#**.

This package has two halves that meet at the contract below:
- `src/` (TypeScript): the exporter. It turns an AIGE project into a Godot project and drives Godot (build, headless play-tests, screenshots, editor, exe export).
- `runtime/` (C#): the AIGE runtime for Godot, namespace `Aige`. It is copied into every exported project as `addons/aige/`, and it brings AIGE components, cutscenes, voice lines, story state, HUD and the test harness to life.

Target: **Godot 4.7.2 .NET** (`Godot.NET.Sdk/4.7.2`, `net8.0`), installed by `aige godot setup` to `~/.aige/godot/`.

## Project layout: the game folder *is* the Godot project

```
games/<game>/
  project.json  scenes/*.scene.json  cutscenes/*.cutscene.json  models/*.model.ts   AIGE sources
  materials/*.material.json  textures/**  audio/**  voices/**                          AIGE sources
  scripts/**/*.cs          game C# scripts (written by the AI, never touched by export)
  project.godot            generated; the [application] name/icon are kept if edited
  <Game>.csproj            generated once (Godot.NET.Sdk), then left alone
  export_presets.cfg       generated ("Windows Desktop", includes *.json)
  addons/aige/**           AIGE C# runtime (overwritten on every export: do not edit)
  godot/                   generated by export (do not edit):
    scenes/<scene>.tscn      one per AIGE scene
    models/<name>-<hash>.glb baked recipes, materials and textures embedded
    materials/<name>.tres    StandardMaterial3D for primitives
    audio/ambience/<kind>.ogg  looping ambiences (baked from AIGE's procedural synth)
    audio/sfx/<preset>.ogg     one-shot story sounds (thunder, creak, door_open, gasp, cough, ...)
  .godot/                  Godot's cache (gitignored)
```

`res://` is the game folder, so `res://audio/voice/hero_wake_1.ogg` and `res://cutscenes/cs1_wake.cutscene.json` work as they are. The runtime reads AIGE JSON documents with `FileAccess` + `System.Text.Json`; the export preset includes `*.json`.

## Autoloads (declared in project.godot)

| Name | Script | Role |
|---|---|---|
| `Story` | `res://addons/aige/Story.cs` | Flags, inventory, objectives, `Emit(event)`; signals for each change |
| `Hud` | `res://addons/aige/Hud.cs` | CanvasLayer: subtitles, interaction prompt, objective + waypoint pointer, fades/letterbox, screen FX shader (vignette, grain, blur, darken, desaturate, flash, temperature/tint) |
| `Voice` | `res://addons/aige/Voice.cs` | `Play(id, actor?)`: loads `res://audio/voice/<id>.json` (VoiceLineDoc) + audio, shows the subtitle, drives the actor's Animator mouth from the `mouth` curve |
| `Sfx` | `res://addons/aige/Sfx.cs` | `Play(preset, position?)` for `res://godot/audio/sfx/<preset>.ogg` or any `res://` audio path |
| `Cutscenes` | `res://addons/aige/Cutscenes.cs` | `Play(path)`, `IsPlaying`, `Skip()`: runs a CutsceneDoc |
| `AigeTest` | `res://addons/aige/Testing/AigeTest.cs` | Test harness; inactive unless `--aige-test=` is passed |

## Input actions (declared in project.godot)

`move_forward` (W, Up), `move_back` (S, Down), `move_left` (A, Left), `move_right` (D, Right), `sprint` (Shift), `jump` (Space), `crouch` (C), `interact` (E, gamepad X/Square), `attack` (left mouse), `skip` (Space, Enter, Esc; hold to skip cutscenes), `pause` (Esc). Mouse motion and the right stick orbit the camera (read directly in the camera script).

## Scene mapping (AIGE scene → .tscn)

The root node is `Node3D`, named after the scene, with `metadata/aige_scene = "<name>"`. Each entity becomes a node, parented as in AIGE:

- **Name**: entity name (made unique among siblings with a `_2` suffix). **Metadata**: `aige_id` (string), `aige_tags` (PackedStringArray). **Groups**: the entity tags (for example `Player`).
- **Transform**: `transform = Transform3D(...)`, computed exactly from position, quaternion and scale. AIGE and Godot agree: Y up, meters, right-handed; cameras and lights look along -Z; models face +Z.
- **Node type**, first match wins:
  1. A `Script` whose `script` is a `.cs` file: the C# class's base type (for example `CharacterBody3D`), with `script = res://scripts/X.cs`. Props become property assignments with the prop names as written, so the AI names props exactly like the C# `[Export]` members.
  2. `CharacterController` → `CharacterBody3D` with a child `CollisionShape3D` named `Shape` (CapsuleShape3D from height/radius, centered at height/2).
  3. `RigidBody` dynamic → `RigidBody3D`; kinematic → `AnimatableBody3D`; fixed → `StaticBody3D`.
  4. `Door` → `AnimatableBody3D` (the door swings with its collision).
  5. Otherwise `Node3D`.
- **Colliders** (non-trigger) on a plain `Node3D` entity: a child `StaticBody3D` named `Body` with one `CollisionShape3D` per Collider (box, sphere, capsule, cylinder, or a convex/trimesh shape of the baked mesh; `auto` = box fitted to the model bounds). On body entities, the shapes are direct children.
- **Trigger colliders** (`isTrigger`): a child `Area3D` named `Area` holding their shapes (collision layer 0, mask 1 = bodies).
- **MeshRenderer**: a child named `Mesh`, either an instance of `res://godot/models/<name>-<hash>.glb` or, for primitives, a `MeshInstance3D` with BoxMesh/SphereMesh/CylinderMesh/CapsuleMesh/PlaneMesh/TorusMesh (unit size) and `material_override`. Shadows follow `castShadow`. Hidden if `visible: false`.
- **Light**: child `Light` = `DirectionalLight3D` / `OmniLight3D` / `SpotLight3D` (`light_color`, `light_energy` = intensity, `omni_range`/`spot_range` = range or 30 if 0, `spot_angle` = angle, `shadow_enabled` = castShadow). Ambient/hemisphere lights are folded into the environment's ambient light. `flicker > 0` adds a child `Node` named `Flicker` running `res://addons/aige/Components/LightFlicker.cs` (prop `Amount`), which drives its parent light (C# cannot subclass `Light3D`).
- **Camera**: child `Camera` = `Camera3D` (`fov`, `near`, `far`, `current` = primary).
- **AudioSource**: child `Audio` (`AudioStreamPlayer3D` if spatial, else `AudioStreamPlayer`) with `res://addons/aige/Components/AudioSource.cs`. `Stream` is the clip, or `res://godot/audio/ambience/<kind>.ogg` / `res://godot/audio/sfx/<preset>.ogg`. Props: `Volume` (0..1), `Loop`, `PlayOnStart`, `Range` (m). The script sets looping on the stream at runtime.
- **Environment**: every Environment component is written as its own resource, `res://godot/environments/<scene>-<entity>.tres`. It covers tonemap, exposure, sky or HDRI panorama, fog + height fog, volumetric fog, SSAO, SSIL, SDFGI, glow and adjustments, and stores its screen-space extras as `metadata/aige_fx = {"vignette", "grain", "temperature", "tint", "lightShafts"}`.
  - The first *active* one is used by a root-level `WorldEnvironment` named `Environment`, which runs `res://addons/aige/Components/EnvironmentFx.cs` with props `Vignette`, `Grain`, `Temperature`, `Tint` and `LightShafts`. EnvironmentFx hands the extras to `Hud`.
  - To change the look at runtime (for example night → morning), game C# assigns another resource: `env.Environment = GD.Load<Environment>("res://godot/environments/house-Morning.tres")` or `EnvironmentFx.Switch(path, fadeSeconds)`. EnvironmentFx then reads the new resource's `aige_fx` metadata.
- **Gameplay components** become child nodes named after the component type (`Interactable`, `Door`, `Trigger`, `Trigger_2`, `ParticleSystem`, `Animator`, ...). Each is a `Node3D` with `script = res://addons/aige/Components/<Type>.cs`, and its props are the AIGE schema fields in PascalCase (`requireFlag` → `RequireFlag`, `cutscene` → `Cutscene` as a `res://` path). Optional fields that are unset are omitted. Schemas: `packages/core/src/schema/components.ts`.
  - `Interactable`: the player's interaction system (in `PlayerController`) picks the nearest enabled Interactable within `Range` in front of the player, shows `Hud` prompt "E  <Prompt>", and on `interact` calls `Interact()`, which plays the cutscene/voice/text, gives the item (and hides the entity), and sets the flag. `RequireFlag` gates it.
  - `Door`: swings its parent entity around local Y to `OpenAngle` at `Speed`. Locked until `UnlockFlag` is set (shows `LockedText`). It acts as an interactable with `Prompt`.
  - `Trigger`: connects to the sibling `Area` (`body_entered`, bodies in group `Tag`), waits `Delay`, then does its effects (cutscene, voice, sound, text, objective, flag). `Once` and `RequireFlag` apply.
  - `ParticleSystem`: GPUParticles3D presets (dust motes in light, rain, snow, embers, fireflies, smoke, sparks, leaves) in the `Area` box.
  - `Animator`: finds the `AnimationPlayer` inside the sibling `Mesh` GLB. API: `Play(clip, fade = 0.25f, loop = null, speed = 1f)`. With `Locomotion` it blends idle/walk/run from the parent body's velocity while no clip overrides it. `Mouth` (0..1) drives the jaw bone (`jaw`) or a `mouth_open` blend shape.
- **Built-in scripts**: `builtin:<Name>` maps to `res://addons/aige/Builtins/<Name>.cs` (props in PascalCase). Needed: `PlayerController` (realistic third-person movement relative to the camera: walk, run, crouch, gravity, step-up, footsteps on wood, interaction) and `ThirdPersonCamera` (over-the-shoulder SpringArm3D rig like Elden Ring/Zelda; props `Target` = entity name, `Distance`, `Height`, `Shoulder`, `Fov`, `MouseSensitivity`, `MinPitch`, `MaxPitch`; collision pull-in; recenters behind the player while moving; yields to cutscene cameras).

## Documents read at runtime

Schemas live in `packages/core/src/schema/documents.ts`:
- **CutsceneDoc** (`res://cutscenes/*.cutscene.json`): `tracks[]` of `camera` (keys with position/target/fov/ease), `animation` (actor + timed clips), `move` (actor transform keys), `voice` (timed voice lines), `sound`, `subtitle`, `fx` (fade, vignette, blur, darken, desaturate, flash, shake, letterbox, heartbeat), `light` (tween a light entity), and `event` (setFlag, clearFlag, enable, disable, give, take, objective, teleport, emit).
  - Actors and lights are referenced by entity id, entity name or path (`Level/Kitchen/Fridge`). Resolve them by `aige_id` metadata first, then by name path, then by unique name.
  - During a cutscene, player input is disabled and a dedicated cutscene `Camera3D` is current. With `returnControl` the gameplay camera and input return at the end. `skippable` allows holding `skip`.
- **VoiceLineDoc** (`res://audio/voice/<id>.json`): `speaker`, `text` (the subtitle), `audio` (a `res://` relative path), `duration`, `fps`, `mouth[]` (0..1 per frame).

## Test harness (`AigeTest`)

Run `Godot --headless --path <game> --fixed-fps 60 -- --aige-test=<abs test.json> --aige-report=<abs report.json> [--aige-scene=res://godot/scenes/x.tscn]`. Screenshots need a window, so leave out `--headless`.

Test file:
```json
{ "seconds": 30, "timeScale": 1, "skipCutscenes": false,
  "teleport": [{ "at": 0, "entity": "Hero", "position": [1, 0, 2], "yaw": 180 }],
  "inputs": [
    { "at": 1.0, "action": "move_forward", "type": "down" },
    { "at": 2.5, "action": "move_forward", "type": "up" },
    { "at": 3.0, "action": "interact", "type": "tap" },
    { "at": 3.5, "look": [120, 0] } ],
  "probes": ["Hero"], "captureAt": [5, 12], "capturePrefix": "<abs dir>/shot" }
```

The report is JSON, written at the end or on a crash, and then Godot quits:
```json
{ "ok": true, "seconds": 30, "errors": ["..."], "logs": ["..."],
  "events": [{ "t": 3.1, "type": "interact", "data": { "entity": "Photo1", "prompt": "Examine" } }],
  "probes": { "Hero": [{ "t": 0.5, "position": [0, 0, 0], "yaw": 0 }] },
  "final": { "flags": [], "inventory": [], "objective": "", "cutscene": null, "scene": "house" },
  "screenshots": ["<abs path>.png"] }
```

Event types: `flag_set`, `flag_cleared`, `item_given`, `item_taken`, `objective`, `interact`, `door_open`, `door_locked`, `trigger`, `cutscene_start`, `cutscene_end`, `voice`, `sound`, `emit`, and `log`.
